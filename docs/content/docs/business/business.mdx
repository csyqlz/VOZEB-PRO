# 商务合作

如果你希望围绕 VOZEB PRO 做商业合作、私有化部署、二次开发或模型渠道接入，可以直接通过邮箱联系项目维护者。

## 商业授权

- 企业自营闭源年度授权：价格请通过邮箱或 QQ 咨询，用于一个企业主体闭源运营一个自有网站、SaaS、应用或内部系统。
- 企业自营闭源永久授权：价格请通过邮箱或 QQ 咨询，用于永久闭源使用授权书列明的版本，不自动包含后续版本。
- OEM、贴牌、私有化项目和其他第三方闭源交付不在标准方案内，不能用自营闭源授权替代；只有另行评估并签署明确书面授权后才可能实施。

商业授权报价只包含一个授权主体、一个自营产品或品牌范围内的软件闭源使用权，不包含多个独立产品、第三方交付、部署、定制开发、技术支持、模型 API 或服务器费用。具体允许事项和限制见[商业授权](/docs/business/commercial-license)。

## 适合沟通的方向

- 私有化部署、内网部署和团队版落地。
- 定制画布节点、生成流程、素材管理或后台能力。
- 接入自有 OpenAI 兼容接口、模型渠道或提示词仓库。
- 围绕 AI 图片、视频、文本生成工作流做联合方案。
- 商业授权、技术支持、交付咨询或联合方案评估。

## 建议提供的信息

- 你的业务场景和预期用户规模。

- 需要接入的模型、渠道、支付或账号体系。
- 期望的交付范围、时间和预算区间。

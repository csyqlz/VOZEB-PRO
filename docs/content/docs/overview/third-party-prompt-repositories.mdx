# 第三方 GitHub 提示词仓库

VOZEB PRO 的内置公共提示词库来自 [`tigerowo/awesome-gpt-image-2-prompts`](https://github.com/tigerowo/awesome-gpt-image-2-prompts)，当前固定到提交 `60e9c65baecfd6d6d51ac4e4d87f146af834bb64`，避免上游内容变化导致同一版本的数据不可复现。

同步脚本读取上游 7 个简体中文分类文件，生成可重复导入的内置种子；旧的多仓库内置种子会被替换，管理员手工维护的公共提示词与用户“我的提示词”不会被删除。上游提示词中的 JSON、`{argument}` 参数模板和转义文本会在同步边界转换为可直接复制使用的可读大纲，页面不会把原始代码结构当作提示词展示。

上游采用 `CC0 1.0 Universal`。当前同步结果以脚本实际校验数量为准；第三方人物肖像、商标、隐私和其他权利不因 CC0 自动获得授权，公开运营前仍需按业务场景审核。

上游图片不会复制进项目或素材库。页面按需通过站内代理读取固定提交下的 GitHub 远程图片，限制文件大小和像素后转换为限宽 WebP，并只使用有限的进程内缓存；加载中或加载失败时显示站点“无限进化”Logo，只有用户主动保存提示词时才创建自己的文本素材记录。
